# 이종현 · AMR / Robotics Engineer

[포트폴리오](https://jonghyeon9084.github.io/)를 배포하는 정적 웹사이트입니다. 별도 빌드가 필요하지 않습니다.

## 구성

이력서의 순서에 맞춰 구성했습니다.

1. 7s_FA — ROS 2 다중 모바일 로봇 스마트팩토리
2. 차팔이 — STM32 물품 수거 로봇
3. POCO — VisionPoseCoach에서 능동형 모니터암으로 확장한 1·2차 프로젝트
4. PLC — 식품 자동 분류 및 창고 관리

프로필 사진, 실제 제작 사진, 아키텍처·HMI 화면, 원본 시연 영상을 포함합니다. 이미지는 클릭하면 확대되며 영상은 사용자가 재생할 때 로드합니다. POCO YouTube 플레이어도 클릭 시 로드합니다. 상단 PDF 버튼은 브라우저 인쇄 창을 열고 A4 세로 인쇄 스타일을 적용합니다.

## 수정 및 미리보기

- index.html: 내용과 미디어 연결
- styles.css: 공통 기술 설명 컴포넌트
- redesign.css: 웹·모바일·인쇄 레이아웃
- app.js: 이미지 확대, 영상 플레이어, 메뉴 상태
- assets/: 사진과 영상

저장소에서 python -m http.server 8765 --bind 127.0.0.1 실행 후 http://127.0.0.1:8765 에서 확인합니다.

2026-10-15 확인 기준. 사용자 제공 이력서, 발표자료, 개발보고서, AMR 저장소와 진행 기록을 대조했습니다. 진행 중 항목과 완료한 시연을 구분하고, 개인 역할과 팀 통합 결과를 명시합니다. 도킹 제어 설정값을 실측 정밀도로 표현하지 않습니다. POCO 자세 모델 지표를 개인 졸음 모델 성능으로 표현하지 않습니다. PLC 단축률은 원시 측정값으로 계산합니다.
