# 이종현 · Robotics & Embedded Software

GitHub Pages용 정적 포트폴리오입니다. 별도 빌드나 서버 의존성이 없습니다.

## 구성

- 공장 자동화: 2페이지
- 온디바이스 AI 1차: 중간 1페이지 + 최종 1페이지
- 온디바이스 AI 2차 POCO: 2페이지
- STM32: 2페이지
- PLC: 2페이지
- 소개·프로필 별도

`index.html`의 내용을 수정하고 `styles.css`에서 디자인을 변경합니다. 모바일에서는 각 페이지가 내용에 맞춰 길어집니다. 인쇄 버튼은 브라우저 인쇄 창을 열며 A4 가로 레이아웃을 적용합니다.

## 배포

GitHub 저장소 Settings → Pages → Deploy from a branch → main / (root)를 선택합니다. `index.html`, `styles.css`, `app.js`, `favicon.svg`, `.nojekyll`, `assets/`를 함께 업로드합니다.

## 콘텐츠 기준

2026-09-27 제공 자료 기준. 진행 중 기능은 완료 성과로 표현하지 않았습니다. POCO의 수치는 팀 통합 결과와 개인 담당을 구분합니다. PLC 시간 단축률은 원시 측정값에서 재계산했습니다. 원본 프로필·팀 문서·학습 데이터는 공개 저장소에 포함하지 않습니다.
